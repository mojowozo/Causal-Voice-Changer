# Upstream notice

The audio engine and COSMIC front end in this folder are derived from
RVC-Realtime-GUI, itself a derivative of
[RVC-Project/Retrieval-based-Voice-Conversion-WebUI](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI).
The RVC inference code has been removed; what remains is the device routing,
recording, file input, metering and user interface, driving CausalVC voices.
